# Wimby – איפה האוטובוס שלי?!

אפליקציית ווב חינמית, מהירה ו-100% פרטית (PWA) לתיעוד זמני המתנה לתחבורה ציבורית בישראל, אימות נסיעות מול מאגר הנתונים הפתוח של **דאטאבוס (OpenBus)**, והגשת תלונות למשרד התחבורה ולחברות המפעילות.

🔗 **כניסה לאפליקציה:** https://wimby-app.github.io/

---

### מה יש באפליקציה?
- **תיעוד מהיר בתחנה:** כפתור "הגעתי לתחנה" עם טיימר חי שממשיך לרוץ גם כשהמסך כבוי, סיווג מהיר של התקלה (*אוטובוס לא הגיע*, *איחור חריג*, *דילג על התחנה*, *עמוס ולא עצר*), ותיעוד ידני / עריכה בדיעבד.
- **קווים שמורים (מועדפים):** ניהול מספר קווים ותחנות (למשל הלוך וחזור) עם החלפה מהירה בלחיצה.
- **אימות מול דאטאבוס (OpenBus / Stride API):** הצלבה ישירה מהדפדפן מול נתוני משרד התחבורה הפתוחים (הסדנא לידע ציבורי) לבדיקת נסיעות מתוכננות (GTFS) מול ביצוע GPS בפועל (SIRI).
- **אשף הגשת תלונה:** הפקת נוסח רשמי מוכן לשליחה (עם התראה על מגבלת 60 הימים), פתיחת טיוטת מייל מוכנה למשרד התחבורה (`pniotcrm@mot.gov.il`) או למפעיל, שיתוף עם קובץ CSV מצורף במובייל, או העתקה ופתיחה של טופס `gov.il`.
- **100% פרטי וללא שרת:** כל הנתונים נשמרים אך ורק מקומית במכשיר (`localStorage`), עם אפשרות לגיבוי ושחזור JSON וייצוא CSV לאקסל.
- **עובד אופליין (PWA):** ניתן להוסיף למסך הבית בטלפון (אייפון ואנדרואיד) לשימוש מיידי גם ללא קליטה.
